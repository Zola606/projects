# 10 — Cloud Identity Security Baseline

Define an identity inventory containing role, owner, MFA state, last use,
privilege, employment/vendor status, and review date. Enforce phishing-resistant
MFA where supported, separate admin identities, remove stale access, and run
quarterly reviews. Report aggregate coverage rather than exposing personal
records.

**Evidence:** control matrix, synthetic inventory, remediation tickets,
privileged-access review, and metrics before/after. Provider-specific commands
must be added only from approved vendor documentation.
