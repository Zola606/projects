# 07 — Phishing Investigation and Response

Run a tabletop using a synthetic email and headers. Verify sender
authentication, identify affected recipients, preserve the original message,
reset or revoke sessions through approved administration, block indicators in
defensive controls, and notify stakeholders without spreading the lure.

**Evidence:** timeline, decision log, evidence hash list, containment checklist,
user message, lessons learned, and recovery verification. Do not send the
sample to real recipients or visit links from an untrusted message.
