# 06 — IPv6 small-office migration

**Real problem:** address growth and dual-stack compatibility are often
introduced without an access policy. Build dual-stack staff and guest VLANs,
advertise a documented /64, and apply IPv6 ACLs equivalent to the IPv4 policy.

**Validate:** IPv6 autoconfiguration, `ping` and HTTP to the lab server,
guest isolation, and a written plan for DNS and monitoring.
