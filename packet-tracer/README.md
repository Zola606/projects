# Packet Tracer project packs

These ten lab packs model real operational problems reported in Cisco design
and troubleshooting guidance. Open Packet Tracer, build the topology described
in each folder, paste the lab configuration, save the resulting file as
`topology.pkt`, and record the validation evidence in the README.

Packet Tracer is installed locally at `/usr/lib/packettracer/packettracer.AppImage`.
The `.pkt` format is proprietary and is not generated by these text files; the
packs are deliberately reproducible instead of pretending that a placeholder
binary is a working lab.

Sources: [Cisco DHCP troubleshooting](https://www.cisco.com/c/en/us/support/docs/ip/dynamic-address-allocation-resolution/27470-100.html),
[Cisco STP troubleshooting](https://www.cisco.com/c/en/us/support/docs/lan-switching/spanning-tree-protocol/10556-16.html),
[Cisco Unified Branch Design](https://www.cisco.com/c/en/us/td/docs/solutions/CVD/Campus/cisco_unified_branch_design_guide.html),
and [CISA SMB guidance](https://www.cisa.gov/audiences/small-and-medium-businesses/secure-your-business/smb-resources).
