# 14 — Network Monitoring and Capacity Baseline

Create a monitoring design for availability, interface errors, CPU/memory,
routing changes, VPN state, and bandwidth. Use SNMPv3, authenticated time,
centralized syslog, and flow metadata with a documented retention period.
Define alert thresholds and escalation ownership before enabling notifications.

**Evidence:** metric dictionary, baseline dashboard mock-up, alert runbook,
maintenance suppression rules, and a synthetic outage test.
