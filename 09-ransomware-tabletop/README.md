# 09 — Ransomware Tabletop and Recovery

Facilitate a 90-minute exercise with timed injects: suspicious encryption,
offline-system impact, a supplier notification, and media questions. Decide
who can isolate systems, how care/services continue, how evidence is preserved,
and how backups are validated. Never use live ransomware or destructive tests.

**Evidence:** roles and contacts, inject cards, decision log, recovery
priorities, backup-restore proof, regulatory/legal escalation assumptions, and
after-action improvements.
