# 04 — Small-ISP Edge Routing and Anti-Spoofing

Model a small ISP with two upstreams, customer prefixes, BGP policy, and a
dedicated management VRF or subnet. Apply prefix filters, maximum-prefix
limits, uRPF or documented anti-spoofing controls, and an out-of-band
operations plan. Keep the lab private and use documentation prefixes only.

**Evidence:** routing policy, accepted/rejected prefix tests, convergence
timings, interface error baseline, and an abuse/contact escalation workflow.
Production peering requires the upstream's technical and security review.
