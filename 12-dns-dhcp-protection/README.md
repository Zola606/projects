# 12 — Protected DNS and DHCP Services

Model approved DHCP/DNS servers, relay paths, trusted switch ports, lease
monitoring, and an offline continuity mode. Use DHCP snooping bindings,
rate-limited client ports, DNS allow-listing where appropriate, and clear
ownership for address conflicts.

**Evidence:** service-flow diagram, binding inspection, rogue-server negative
test in an isolated lab, outage runbook, and privacy-aware log-retention plan.
