# 13 — Least-Privilege Remote Access VPN

Design separate remote-access profiles for staff, contractors, and support.
Require MFA, posture checks where available, split access by approved
application, and log authentication and policy decisions. Include a lost
device process and a low-bandwidth user experience review.

**Evidence:** role-to-resource matrix, MFA failure handling, session logging
fields, revocation test, and support runbook. Do not use real identities.
